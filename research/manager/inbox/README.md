# Manager inbox

Agents put a short note here before any *impactful* change (see the sign-off rule
in `CLAUDE.md` and each agent's definition). File name: `<agent>-<yyyy-mm-dd>-<slug>.md`.
Each note: what, why, files touched, risk, how to undo. The manager approves,
sends back, or escalates to Elliot, and records the outcome in `../decision_log.md`.
Move handled notes into `handled/` (don't delete them).
